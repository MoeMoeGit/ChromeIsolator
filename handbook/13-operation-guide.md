# 使用与管理指南

> 适用状态：启用
> 读者：ChromeIsolator 用户与本机管理员
> 适用源码版本：1.7.11；核对日期：2026-09-26

完整功能介绍、安装与源码构建见项目根 [README](../README.md)。本文只保留容易误操作的运行与恢复步骤。

## 创建和使用环境

1. 启动“浏览器多开”。首次运行按提示使用已安装的 Chrome，或明确安装官方 Stable Chrome；仅在 Chrome 不可用时选择 Edge 临时备用。
2. 默认环境为 p1、p2、p3。点击“添加环境”会使用最小可用编号并提示命名；可通过右键或详情区编辑名称和最多 120 字的备注。
3. 双击未运行环境或点击启动；双击运行中环境会将对应浏览器带到前台。
4. 关闭主窗口只会隐藏到系统托盘。需要完全退出时，在托盘选择退出，应用会先关闭受管浏览器。

## 采集、差异和外部链接

- 在设置的环境模式入口中，仅对已关闭环境切换模式。采集模式供本机工具连接已登录环境；差异模式只改变两个 navigator 属性。一般使用保持基础模式。
- 外部链接可选择固定环境，也可保持“自动选择”，自动使用最小编号环境。“设为默认浏览器”会打开 Windows 设置，最终选择仍需用户在系统界面完成。

## 删除、卸载与恢复

- 删除环境会删除该环境的全部登录状态、Cookie、密码、扩展和缓存。确认对话框输入 `delete` 后，目录先进入 Windows 回收站；需要恢复时，在回收站尚未清空前还原原目录。
- 卸载应用默认保留 `%LOCALAPPDATA%\ChromeIsolator`。彻底清理前先确认不再需要任何环境；手动删除该目录是不可从应用内撤销的操作。
- 配置异常时应用会尝试 `config.json.bak`。排查前先退出应用并备份整个用户数据目录，不要只复制配置而遗漏 Profiles。
- 浏览器无法启动时，先确认 profile 未被其他 Chrome/Edge 进程占用，再在详情区重试；不要改用用户默认浏览器 profile 绕过问题。
