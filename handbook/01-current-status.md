# 当前状态

> 更新时间：2026-09-27
> 核对依据：1.7.12 源码与双仓库自查结果
> 阶段：源码版本 1.7.12，最新已发布版本仍为 1.7.9

## 活跃任务

1.7.12 为当前源码交接版本，整合三语言与统一组件规范：普通/主要操作 32 点高、快捷操作 28 点、设置操作列 156 点；默认浏览器入口与其余设置操作使用同档中性样式。主窗口、设置、模式管理、输入与错误恢复路径复用公共组件。本次仅提交推送 main 源码，不创建发布标签或 Release，不替换已安装程序；既有功能与数据兼容约定不变。

## UI 工作区交接

- main 上新增浅色、深色、跟随系统及兼容默认值；调整主窗口操作权重、设置顺序、文字层次、焦点、模式与下载窗口的主题资源。已提交基线之上新增按钮一致性修正，未新增依赖。
- 列表标题使用受限宽度与省略号，错误标识和行内操作独立保留空间；输入、删除确认与提示弹窗的图标使用动态主题绑定。
- 当前机器为 macOS，Windows 主窗口、设置、原生对话框、主题实时切换、高对比度、低图形层级、键盘导航、混合 DPI、长文案与所有状态均未实机视觉验收；静态检查和编译不能替代这些验收。

## 当前能力与变更

- 保留已有环境管理、托盘、Chrome/Edge 引导、外链、三语言、四种模式、ZIP/MSI 能力。
- 新建默认值与 macOS 一致，旧配置及磁盘重建不迁移为采集开启；首次生成配置立即保存。
- 修复关闭期间的进程跟踪、重复关闭、旧退出回调、端口预留冲突、外链关闭竞态、异步磁盘扫描集合变化。
- 配置空值进入恢复链路，损坏副本尽力保留，保存失败保留内存状态并提示；缺失目录保留元数据。删除先保存配置，移动失败回滚，避免保存失败后补建空环境。
- 批量采集按筛选结果一次保存，无可修改项时禁用，空筛选显示提示；高级引擎信息刷新与三语言默认环境名已修复。
- CDP 清理不再无限等待关闭握手，连接超时进入重试。

## 验证与限制

- 本版本 UI 代码使用临时 .NET 8.0.100 在 macOS 重新交叉编译 WPF Release，通过且 0 警告、0 错误；未升级项目目标框架或依赖。
- `tests/CompatibilityTests` 使用生产配置/端口源码及临时假数据验证，已接入 Windows CI；32 项断言通过（含外观默认值与持久化、删除回滚与受控子进程启停）；10 个 XAML 解析通过，三语言各 164 个资源键一致，文档与差异格式检查通过。
- 未运行 Windows UI、真实 Chrome/Edge/CDP、回收站、默认应用注册、管道外链、MSI 安装升级。交叉编译不能替代这些验收。
- 综合对齐报告保存在 macOS 仓库的 `docs/windows-alignment.md`。代码自查不是独立评审。
