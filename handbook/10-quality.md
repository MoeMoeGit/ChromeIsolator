## 验证入口与完成标准

| 范围 | 入口 | 通过条件 | 限制 |
| --- | --- | --- | --- |
| 编译 | `dotnet build ChromeIsolator.sln -c Release` | 无错误，版本来自 `Directory.Build.props` | 需要 Windows/.NET 8；macOS 不能完整验证 WPF |
| 便携发行 | `scripts/publish-win-x64.ps1` | 生成 self-contained win-x64 目录和带版本 ZIP | Windows PowerShell |
| MSI | `scripts/build-msi.ps1` | WiX 成功生成带版本 MSI | 需要 WiX 7 和扩展 |
| 文档 | `python handbook/tools/check_docs.py --strict-init` | 0 个错误；提醒需人工判断 | 只检查结构、链接和核心占位 |
| UI | Windows 实际运行主窗口、设置、模式窗口、托盘和弹窗 | 主路径与空/错/过渡/禁用/多语言状态正确 | 构建不能替代视觉检查 |
| 浏览器生命周期 | 启动、前置、单关、全关、手动关浏览器、退出 | 状态一致，无串 profile、卡死或遗留受管进程 | Chrome/Edge 和真实 profile 锁需实机 |
| 外部链接 | Windows 默认应用 + 第二实例管道 | http/https 路由正确，失败有可恢复反馈 | Windows 10/11 实机 |
| 配置恢复 | 人工损坏主配置/备份的隔离样本 | 备份恢复或磁盘重建符合提示，不丢真实数据 | 必须先备份并使用测试数据 |

## 回归经验

- 进程退出事件、批量停止和 UI 命令并发时，复核字典锁、UI 线程切换、幂等释放和失败后的状态恢复。
- 修改 ListBox 布局时验证列表项真正横向拉伸；过去的根因是 `DockPanel` 子元素填充关系，不应再用硬编码 `MinWidth` 补偿。
- WPF 资源需验证 MSI 后的实际加载；应用图标使用嵌入资源，XAML `FallbackValue` 不使用 `DynamicResource`。
- 托盘需在首次右键、左键唤醒和混合 DPI 显示器上检查；原生 `ContextMenuStrip` 与 `PerMonitorV2` 是当前方案。
- MSI 升级不能强制结束应用，否则会绕过浏览器关闭流程；同版本 MSI 不作为正式升级路径。
