# UI 与交互约定

> 适用状态：启用；当前代表页面是主窗口。

## 设计方向与入口

应用采用原生 Windows 桌面体验：支持浅色、深色及跟随系统，克制、信息密度适中，以环境列表和当前环境操作为中心，不照搬 macOS 界面。

| 内容 | 唯一维护位置 / 参考 |
| --- | --- |
| 颜色与画刷 | `src/ChromeIsolator.App/Themes/Colors.xaml`、`Services/ThemeService.cs` |
| 控件样式 | `src/ChromeIsolator.App/Themes/Controls.xaml` |
| 代表页面 | `src/ChromeIsolator.App/MainWindow.xaml` |
| 设置与环境模式 | `SettingsWindow.xaml`、`EnvironmentModeWindow.xaml` |
| 文案与本地化 | `Resources/Strings*.xaml`、`Services/L10n.cs` |
| 图标 | `assets/icons/AppIcon.ico`，由 `IconHelper` 从嵌入资源加载 |

## 主题与视觉层次

- `ThemeService` 统一切换语义画刷；XAML 使用 DynamicResource，代码创建的弹窗文字、图标及表面使用 SetResourceReference，使已打开窗口响应外观变化。新增配置 `Appearance`，旧配置缺字段时为 system，未知值按 system 处理。
- 设置顶部集中外观、语言和高级详情；主操作使用蓝色，危险操作使用错误语义色。详情标题 20、正文 13、辅助文案 12，间距以 8 / 12 / 16 / 24 为节奏。
- 工具栏与侧栏采用轻度透明表面，内容卡片保持不透明。不引入背景截图、模糊、窗口钩子或第三方效果依赖。系统关闭透明度或图形层级不足时使用实色；高对比度使用系统画刷。
- 恢复按钮与列表键盘焦点提示，行内动作可获焦；长详情标题换行，主操作可折行，下载内容可滚动且窗口可调整大小。
- 保留 Windows 标题栏、系统消息框、托盘、右键和双击行为；原生系统对话框的配色由 Windows 管理。主题变化不改环境模式或配置恢复语义。

## 组件与布局规范

组件先按用途分档，再决定排列；禁止为单个入口临时叠加宽高、字号或强调色覆盖。

| 类型 | 尺寸与视觉 | 布局规则 |
| --- | --- | --- |
| 普通、主要、危险操作 | 最小高 32、正文 12、圆角 6、横向内边距 12；主要操作用蓝色，危险操作用危险色，其余中性 | 内容区最小宽 88，设置及目录操作列宽 156；长标题允许增高 |
| 工具栏、列表快捷操作 | 28 点紧凑档 | 保留原生工具栏与列表行为，图标入口提供辅助名称 |
| 输入框、选择框 | 32 点布局基线，原生控件可有光学高度差 | 与同排按钮垂直居中，长内容可缩略但不能遮挡操作 |
| 设置行与操作组 | 组内间距 8、列间 12、卡片内边距 12 | 单操作靠右，多操作独立成组；空间不足时换行 |

- “设为默认浏览器”属于普通设置操作，与其他设置按钮使用同一组件及操作列；不使用实心蓝色，也不单独降为迷你控件。
- 主操作、重命名、备注和恢复操作保持同档高度；启动/关闭过渡保留按钮位置，避免相邻控件跳动。原生系统确认框不替换为自绘窗口。
- 焦点、按下、禁用、危险色和长文案换行在公共组件中维护；Enter/Escape 与原有命令、禁用条件保持不变。
- 普通说明解释用途与影响，API 字段保留在高级信息和开发文档。

WPF 共享尺寸与状态位于 `Themes/Controls.xaml`：`ControlHeight`、`CompactControlHeight`、`ActionColumnWidth`、`ActionPadding`。窗口与输入弹窗复用 PrimaryButton / SecondaryButton / UtilityActionButton；不在各入口复制尺寸。

## 已确认的交互约定

- 主窗口左侧是可调宽度环境列表，右侧是当前环境详情；窗口位置、尺寸、最大化状态和左栏宽度会持久化。
- 列表项必须横向铺满，运行中/启动中/关闭中/未启动以状态和颜色区分；常用启停动作放在行内。标题以 Grid 的剩余宽度显示并省略超长内容，错误标识和启停操作保留独立空间，不把需省略的标题放入横向 StackPanel。
- 双击未运行环境启动；双击运行中环境将浏览器窗口带到前台，不把双击设计为关闭。
- 备注为空时不占详情空间；错误状态提供重试和清除入口；路径操作提供打开和复制。
- 设置页承担低频全局偏好。大量环境的采集/差异开关放在二级管理窗口，并支持搜索、仅显示可切换环境和采集批量操作。
- 所有用户文案同步维护三份资源；非英语界面的语言标题保留 `Language` 识别锚点。按钮使用动作语义，不使用模糊名词标签。
- 托盘左键唤醒主窗口，右键打开原生菜单；混合 DPI 下保持 `PerMonitorV2`。

## UI 验收

修改界面时至少检查主入口、双击与右键、主要操作、空状态、错误、加载/过渡、禁用状态、长文本语言、窄窗口和混合 DPI。能在 Windows 运行时必须查看真实界面；仅通过构建不能宣称视觉验收完成。

紧凑布局：主窗口侧栏默认 280、最窄 240，保留用户已有分栏宽度；详情标题 20，主窗口及设置卡片内边距 12，设置页边距 16。
