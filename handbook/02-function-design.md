# 功能与业务约定

> 适用状态：启用。这里只维护当前有效行为；历史版本过程由 Git 追溯。

## 当前功能地图

| 功能 / 入口 | 当前行为 | 关键实现 | 验收重点 |
| --- | --- | --- | --- |
| 环境管理 | 默认配置含 p1/p2/p3；新增使用最小空闲 pN；支持重命名、备注、目录、删除 | `ProfileManager.cs`、`MainViewModel.cs` | 目录不串用；运行中/关闭中禁止删除；删除进回收站 |
| 浏览器启停 | 优先 Chrome Stable，用户确认后可用 Edge；独立 `--user-data-dir` | `ChromeManager.cs`、`DownloadWindow` | 不触碰默认浏览器数据；失败能恢复状态并提示 |
| 主窗口 | 环境列表、详情、启动/关闭、路径、错误和高级信息；双击运行中环境会前置窗口 | `MainWindow*`、`MainViewModel.cs` | 空/启动中/运行中/关闭中/错误状态清楚 |
| 托盘与退出 | 关闭窗口隐藏；托盘可启动、关闭、全部关闭、检查更新、退出 | `TrayService.cs`、`App.xaml.cs` | 单实例唤醒；退出前关闭受管环境 |
| 采集模式 | 环境关闭时可切换；开放本机 CDP，支持批量启停配置 | `EnvironmentModeWindow*`、`ChromeManager.cs` | 不自动注入差异脚本；运行中不可改配置 |
| 差异模式 | 稳定覆盖 CPU 核心数和内存值，处理已有和新页面并有限重连 | `FingerprintInjector.cs` | 只覆盖两个 navigator 属性；失败回写警告 |
| 外部链接 | 仅接受 http/https；路由到选定环境或最小编号环境 | `App.xaml.cs`、`MainViewModel.cs`、`ShellService.cs` | 启动中排队；转发失败不静默丢链接 |
| 设置与本地化 | 数据路径、浏览器状态、模式、外部链接、语言、更新 | `SettingsWindow*`、`L10n.cs`、`Resources/` | 三语言可切换；设置即时保存 |
| 安装与更新 | self-contained ZIP、MSI、GitHub Release 检查 | 脚本、WiX、`UpdateService.cs` | 安装升级不删除用户 profile |

## 关键业务规则

- 首次生成及后续新增环境默认开启采集、关闭差异；旧配置缺字段及磁盘恢复仍关闭，不迁移已有环境。
- 环境目录名 `pN` 是身份；展示名为空时由界面生成默认名称。删除低编号环境后，新环境可复用该最小空编号。
- 备注是最多 120 字符的纯文本，只用于识别，不参与账号、同步或自动化逻辑。
- 环境排序：运行/过渡状态优先，其余按最近使用时间倒序；最近使用时间持久化。
- 浏览器缺失时不静默安装。用户可明确安装官方 Stable Chrome，或在 Chrome 缺失时明确启用 Edge 备用。
- 基础模式不开放调试端口。采集模式优先使用 `41000 + N`，差异模式单独使用 `40000 + N`；端口冲突时由分配器寻找可用端口。
- 采集和差异可同时启用：共用采集端口，并继续执行差异注入。
- 外部链接目标未配置时自动选择最小编号环境；没有环境或浏览器未就绪时必须向用户反馈并提供恢复路径。

## 关键用户路径与异常

1. 首次启动：读取/恢复配置并扫描磁盘环境 → 检测浏览器 → 展示隔离说明或安装/备用选项 → 进入主窗口。
2. 启动环境：补建目录 → 选择模式和端口 → 启动浏览器 → 必要时连接 CDP → 更新最近使用和界面状态。
3. 关闭环境：停止注入器 → 优先 CDP `Browser.close` → 窗口关闭 → 超时后结束进程树 → 恢复 UI 状态。
4. 删除环境：确认未运行 → 输入 `delete` 确认 → 保存移除后的配置（同时清空匹配的外链目标）→ 移入回收站；保存失败不移动目录，移动失败回滚配置并提示。
5. 外部链接：第二实例通过当前用户专属命名管道转发；目标未运行则带 URL 启动，启动中则排队，已运行则向同 profile 追加 URL。

重复点击、取消、启动失败、CDP 失败和进程自行退出都不得导致环境永久卡在过渡状态。完整验证入口见 [10](10-quality.md)。
